# chemistry-helper

Tools that help with learning chemistry fundamentals.

## Periodic Table Study Tool

An interactive periodic table (`index.html`) that runs entirely in the browser, with no build step.

- Hover over (or tap) any of the 118 elements for its name, atomic mass, group and period, electron configuration, electronegativity, state at room temperature, discovery year, and a fact.
- Highlight elements by category or by atomic number in groups of 20.
- Flashcards built from a category or an atomic-number range, in either direction (symbol to name, or name to symbol), with a picture cue for each element.
- A typed-answer quiz that keeps score and lets you retry the ones you missed.

To run it locally, open `index.html` in any web browser.
